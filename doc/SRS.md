# SRS - Sistema Integrado de Ventas e Inventario para la tienda de ropa Oscar Montano 
| ID | Requisito |
|---|---|
| REQ-001 | Inicio de sesión del usuario bajo condiciones de bloqueo por intentos y jerarquía de roles |
| REQ-002 | Registrar nuevos productos en el inventario |
| REQ-003 | Registrar clientes con nombre, apellido, DNI y teléfono | 
| REQ-004 | Permitir buscar prendas por nombre, código o categoría y mostrar su stock por talla y color, y su precio | 
| REQ-005 | Registrar ventas de una o más prendas, indicando la cantidad de cada una y el cliente |
| REQ-006 | Calcular automáticamente el total de la venta |
| REQ-007 | Descontar del stock, por talla y color, la cantidad vendida de cada prenda al confirmar la venta | 
| REQ-008 | Generar el comprobante interno de venta con número, fecha, detalle y total |
| REQ-009 | Generar reportes de ventas por rango de fechas |
| REQ-010 | Generar reportes de inventario con el stock actual por prenda, talla y color | 
| REQ-011 | Permitir consultar el historial por fecha | 
| REQ-012 | Mostrar una alerta cuando el stock de un producto (por nombre,  talla y color) sea menor a 10 unidades, al registrar ventas y al consultar el inventario. |
| REQ-013 | El sistema deberá permitir pagos bajo 3 tipos: Efectivo, Yape o Tarjeta |
| REQ-014 | El sistema deberá Permitir Reabastecer productos, agotados o por agotarse |
