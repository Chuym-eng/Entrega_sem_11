
# Documento de Visión Sistema Integrado de Ventas e Inventario para la tienda de ropa “Oscar Montano”
## 1. Propósito
Permitir que los usuarios puedan registrarse, iniciar sesión, buscar contenido y agilizar el servicio al cliente.
## 2. Problema
Falta de integración entre el sistema de emisión de boletas y el control de inventario del sistema.
## 3. Alcance
- Incluye: Atención al cliente, registro de ventas, administración del negocio.
- No incluye: Registro digital, pagos en línea.
## 4. Interesados
| Rol | Necesidad |
|---|---|
| Cliente | Consultar los productos con el menor tiempo de atención posible |
| Cajero | Registrar las ventas de la forma más rápida posible |
| Encargado del almacén | Gestionar el inventario |
| Administrador | Gestionar los precios |
## 5. Objetivos medibles
- Reducir posible perdidas relacionadas con errores de inventario.
- Sustituir de manera progresiva el uso de cuadernos para las operaciones.
## 6. Requisitos de alto nivel (6 y 7 todavía faltan)
- REQ-001: Inicio de sesión del usuario. 
- REQ-002: Registrar nuevos productos en el inventario
- REQ-003: Registrar clientes con nombre, DNI y teléfono. 
- REQ-004: Permitir buscar prendas por nombre, código o categoría y mostrar su stock por talla y color, y su precio. 
- REQ-005: Registrar ventas de una o más prendas, indicando la cantidad de cada una y, opcionalmente, el cliente. 
- REQ-006: Calcular automáticamente el subtotal, el IGV (18 %) y el total de la venta. 
- REQ-007: Descontar del stock, por talla y color, la cantidad vendida de cada prenda al confirmar la venta. 
- REQ-008: Generar el comprobante interno de venta con número, fecha, detalle, subtotal, IGV y total. 
- REQ-009: Generar reportes de ventas por rango de fechas. 
- REQ-0010: Generar reportes de inventario con el stock actual por prenda, talla y color. 
- REQ-0011: Almacenar cada venta confirmada y permitir consultar el historial por fecha. 
- REQ-0012: Mostrar una alerta cuando el stock de un producto sea menor a 10 unidades.
## 7. Restricciones
No hay restricciones actualmente.
